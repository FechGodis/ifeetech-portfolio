HOW TO PREVIEW
1. Extract this ZIP.
2. Double-click index.html to open it in your browser.
3. For best local development, use VS Code + the Live Server extension.

PUBLISH ON GITHUB PAGES
1. Sign in to GitHub and create a NEW PUBLIC repository named: ifeetech-portfolio
2. Upload the CONTENTS of this extracted folder to the repository root (not the ZIP itself).
   Ensure index.html is visible at the top level of the repo.
3. Open repository Settings -> Pages.
4. Under Build and deployment, choose "Deploy from a branch".
5. Select branch "main" and folder "/ (root)", then Save.
6. Wait a few minutes. The public address should be:
   https://fechgodis.github.io/ifeetech-portfolio/
   If you created the repo under a different username, replace fechgodis.
7. If the page does not appear immediately, refresh Settings -> Pages and wait for the deployment status.

IMPORTANT CONTENT NOTES
- Project cards are portfolio presentation concepts; confirm descriptions and replace links with the exact project/demo URLs before presenting them as live work.
- The CV button is intentionally replaced with "Let's talk" because no CV file was provided. Add your CV PDF and a download button when ready.
- The logo concept artwork is a generated raster image with a dark background and glow. The site currently uses a crisp inline SVG monogram for the header and favicon so it stays sharp and readable on the light/dark theme. The PNG is included as a brand exploration, not used as the header logo.
- To edit contact details or text, open index.html in a code editor and search for the relevant text.
- The website uses Google Fonts; the rest of the page works if fonts are blocked, with system fallbacks.
